# Contribuire

Seguire il README per l’avvio e le verifiche. Tenere separate modifiche applicative, editoriali e documentali. Nelle proposte editoriali riportare fonti, provenienza e autore dichiarato. Registrare le decisioni sostanziali in `docs/decisions/`.

Per pubblicare un documento o una revisione seguire le procedure in `docs/`. Conservare i file e i metadati delle versioni pubblicate. Usare esclusivamente fixture sintetiche nei test.

I contributi che dipendono dalla disponibilità di un originale, da diritti editoriali o dalla pubblicazione richiedono verifica del promotore.
